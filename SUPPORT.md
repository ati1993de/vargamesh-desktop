# Support

## Before reporting a problem

1. confirm the installed VargaMesh Desktop version
2. confirm Windows version and x64 architecture
3. allow VargaMesh Core enough time to start/synchronize
4. check the **Node** page and `desktop-runtime.log`
5. check VargaMesh Core `debug.log`
6. reproduce the issue with clear steps when possible

## Useful information for a bug report

- VargaMesh Desktop version
- VargaMesh Core version
- Windows version
- installed Setup or Portable ZIP build
- exact error message
- relevant non-sensitive log lines
- reproduction steps

## Never publish

- WIF/private keys
- wallet passwords/passphrases
- wallet files or backups
- RPC `.cookie` contents
- seed material
- SSH private keys
- API, npm or GitHub tokens

Desktop issues can be reported at:

https://github.com/ati1993de/vargamesh-desktop/issues

Consensus/Core issues belong in:

https://github.com/ati1993de/vargamesh-core/issues
